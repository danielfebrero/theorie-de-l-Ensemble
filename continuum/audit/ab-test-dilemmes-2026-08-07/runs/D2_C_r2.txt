PROCESSUS:

1. OBJECTIF — L'enjeu réel n'est pas seulement un gain financier : c'est la survie de l'entreprise (100 000 € = 18 mois de runway, aucune autre ressource) face à une opportunité statistiquement favorable mais binaire. Critère de succès : améliorer la position financière attendue sans jamais exposer l'entreprise à un risque de disparition, la trésorerie étant l'unique filet de sécurité.

2. OPTIONS —
A) Tout investir (100 000 €) : gain potentiel maximal (220 000 €), mais 45 % de probabilité de trésorerie nulle.
B) Refuser (0 €) : statu quo, 18 mois de runway préservés, aucun gain possible.
C) Investir ~15 000 € (~15 %) : exposition partielle ; représente la famille des mises fractionnées (variantes évidentes non proposées : 5 %, 10 %, 20 %, 30 %, utiles pour situer C dans le spectre).

3. CRITÈRES ET POIDS (somme = 1) —
- Survie / éviter la ruine : 0,35
- Gain moyen attendu : 0,25
- Pire cas et réversibilité : 0,20
- Runway et flexibilité future : 0,15
- Lisibilité de la décision pour les parties prenantes : 0,05

4. INCERTITUDES —
Connu : montants, multiplicateur ×2,2, perte totale en cas d'échec, 18 mois de runway, opération unique, immédiate, non fractionnable dans le temps.
Estimé : p = 55 % de succès, avec « base statistique solide » → probabilité de bonne qualité ; mais une opération unique reste dominée par la variance, pas par la moyenne.
Inconnu : stabilité du burn rate, opportunités alternatives futures, corrélation entre l'échec de l'opération et d'autres difficultés, seuils critiques de runway (ex. pour une levée de fonds).
Qualité globale : bonne pour p, nulle pour ces inconnues → prudence requise sur les paris extrêmes.

5. ÉVALUATION (notes /10, score pondéré) —
Espérances brutes : A → 121 000 € (gain moyen +21 000) ; B → 100 000 € ; C → 0,55×118 000 + 0,45×85 000 = 103 150 €.

Classement provisoire : C > B >> A. Repère complémentaire : la fraction théoriquement optimale pour la croissance du capital sur ce type de pari (critère de Kelly, f* = (0,55×1,2 − 0,45)/1,2) vaut 17,5 % ; miser ~15 %, légèrement en dessous, est cohérent avec une contrainte de survie sur un coup unique.

6. RISQUES —
A : pire cas = trésorerie à zéro, faillite quasi certaine, irréversible ; salariés, clients, fournisseurs, dirigeants tous affectés ; probabilité 45 % → inacceptable.
B : pire cas = coût d'opportunité (gain moyen abandonné) ; réversible en pratique ; personne n'est directement lésé, mais l'entreprise renonce à renforcer son coussin.
C : pire cas = −15 000 €, runway ramené à ~15,3 mois ; réversible par un ajustement modéré des coûts ; impact limité sur l'équipe.

7. STRESS-TEST du choix provisoire (C) —
a) « L'opération est unique : sans répétition, la logique de fraction ne s'applique pas, autant refuser (B). » → La vie d'une entreprise est une succession de paris uniques ; refuser systématiquement les paris favorables dont la perte est absorbable appauvrit sur la durée. Ici la perte maximale (~2,7 mois de runway) est supportable.
b) « Le gain moyen maximal exige de tout miser (A). » → Renversé : la valeur d'un euro n'est pas linéaire ; 45 % de destruction totale de l'entreprise ne peut être compensé par aucun gain moyen. Un pari mortel n'est pas « favorable ».
c) Sensibilité : si p réel = 50 %, C donne encore 101 500 € en moyenne ; le point mort est p ≈ 45,5 %. Avec une base statistique solide, la marge est confortable.
d) « 15,3 mois franchit-il un seuil critique ? » Rien ne l'indique ; on reste au-dessus des seuils usuels de confort (12 mois). Aucun argument ne renverse C ; le concurrent le plus proche est B, écarté car il n'améliore jamais la position.

8. DÉCISION —
Option C : investir ~15 000 €. Plan de repli en cas d'échec : réduire le burn de ~5-8 % pour ramener le runway vers 16-17 mois, geler toute nouvelle opération risquée tant que la trésorerie n'est pas reconstituée au-dessus de 100 000 €, et consigner le résultat pour calibrer les décisions futures.
