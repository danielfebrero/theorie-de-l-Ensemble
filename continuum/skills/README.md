# Adaptateurs de skill

Ce répertoire contient les sources portables des adaptateurs M3C3. Elles sont
distribuables par les profils de `distribution/`, mais ne constituent pas une
preuve d'installation, d'activation ou d'intégration dans les poids d'un
modèle.

L'installation éventuelle doit respecter les règles de l'hôte, rester bornée
à une portée observable et être déclarée dans un rapport d'intégration avec la
classe de preuve exacte.
